[#sec:technicalDocumentationOfBackend]
= Technická dokumentace backendu

Celá aplikace je rozdělena na samostatný backend a frontend.
Backend je postaven na architektuře mikroslužeb.
Skládá se konkrétně ze dvou služeb, které spolu komunikují pomocí brokera zpráv RabbitMQ 3.8.
První služba je implementována ve frameworku Spring Boot 3.1.0 a poskytuje API pro komunikaci s frontendem (tzn. grafickou částí aplikace).
Druhá služba je implementována v jazyce Python 3.11 a vykonává samotné operace načítání modelů ze souboru a generace scén.

[#sec:attributesInApplicationYml]
=== Atributy v application.yml
Tento projekt používá pro nastavení aplikace soubor application.yml.
V tomto souboru jsou umístěny atributy umožňující pozměnit chování aplikace.
Jejich hodnoty lze přepsat při spuštění v Dockeru v souboru `docker-compose.dev.yml`.
Atributy vytvořené specificky pro tento projekt jsou vyobrazeny na následující tabulce (tečka ve vyobrazení indikuje hierarchii).

.Atributy souboru application.yml
[cols=3, options="header",id="tab:attributesInApplicationYml.attributes",options=unbreakable]
|===

|Název pole
|Význam
|Výchozí hodnota

|api.base-path
|Základní URL API, od které se odvíjí všechny další
|/api/v1

|models-controller.base-path
|Základní URL řadiče API pro modely
|models

|models-controller.start-operation.path
|URL operace pro načtení modelu ze souboru

|models-controller.get-value.path
|URL operace pro stažení výsledku operace načtení modelu ze souboru
|getParsedModel

|scenes-controller.start-operation.path
|URL operace pro generaci scén
|generateScenes

|scenes-controller.get-value.path
|URL operace pro stažení výsledku operace generace scén
|getGeneratedScene

|queues.exchange
|Hodnota exchange pro RabbitMQ
|artificial-generation-exchange

|queues.model-parsing.request
|Název fronty pro požadavek na načtení modelu ze souboru
|modelParsingRequest

|queues.model-parsing.response
|Název fronty výsledek požadavku na načtení modelu ze souboru
|modelParsingResponse

|queues.scene-generation.request
|Název fronty pro požadavek na generaci scén
|sceneGenerationRequest

|queues.scene-generation.response
|Název fronty výsledek požadavku na generaci scén
|sceneGenerationResponse

|===

[source,yaml]
----
api:
  base-path: /api/v1

models-controller:
  base-path: models
  start-operation:
    path: parseModelFromFile
  get-value:
    path: getParsedModel

scenes-controller:
  base-path: scenes
  start-operation:
    path: generateScenes
  get-value:
    path: getGeneratedScene

socket-server:
  port: 8085
  host: 0.0.0.0

server:
  port: 8080

queues:
  exchange: artificial-generation-exchange
  model-parsing:
    request: modelParsingRequest
    response: modelParsingResponse
  scene-generation:
    request: sceneGenerationRequest
    response: sceneGenerationResponse


spring:
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 15MB
  rabbitmq:
    host: localhost
    port: 5672
    password: mypassword
    username: myuser
----
