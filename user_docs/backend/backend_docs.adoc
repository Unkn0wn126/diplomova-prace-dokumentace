= Uživatelská příručka backendu aplikace


V této sekci je popsán způsob práce s backendem aplikace pro koncového uživatele.

[#sec:launchBackend]
== Spuštění backendu

Backend lze spustit tradičním způsobem lokálně či pomocí Dockeru.
V prvním případě je potřeba zajistit instanci RabbitMQ a případně poupravit nastavení v application.yml pro projekt ve Springu a soubor .env pro projekt v Pythonu.
// TODO popis .env nastavení pro Python v technické dokumentaci?
Ve druhém případě stačí navigovat příkazovým řádkem to složky se souborem docker-compose.dev.yml a zadat příkaz `docker-compose -f docker-compose.dev.yml up –build`.
Po spuštění tohoto příkazu by měl být backend připraven k použití.

[WARNING]
====
Před spuštěním příkazu popsaného výše zkontrolujte, že má soubor mvnw v projektu ve Springu nastaven konce řádků na hodnotu LF.
V opačném případě nemusí být tento soubor nalezen a proces sestavení této části tak může selhat

[#sec:supportedFormats]
== Podporované 3D formáty

Aplikace využívá pro zpracování 3D formátů knihovnu https://pypi.org/project/assimp-py/[assimp-py].
Z tohoto důvodu by mělo být podporováno až přes 40 formátů (vizte https://assimp-docs.readthedocs.io/en/latest/about/introduction.html[dokumentaci knihovny Assimp]).
Během vývoje byly prakticky otestovány následující formáty:

.fig:modelManagement.modelExportedDialog
* .obj
* .dae
* .fbx
* .glb
* .gltf
* .ply
* .stl
* .x3d
