[#sec:basicAppLayout]
== Základní rozhraní aplikace

Okno aplikace je obecně rozděleno do 4 sekcí (viz <<fig:basicAppLayout.applicationLayout>>).

.Rozdělení aplikace
image::2023-07-29T13-28-19-773Z.png[Rozdělení aplikace,id="fig:basicAppLayout.applicationLayout"] 

V první sekci (<<fig:basicAppLayout.menuBar>>) se nachází nástrojová lišta podobně jako ve standardních aplikacích.
Pro její položky a bližší informace viz <<sec:menuBar>>

.Nástrojová lišta
image::2023-07-29T13-39-53-486Z.png[Nástrojová lišta,id="fig:basicAppLayout.menuBar"] 

Pod nástrojovou lištou se nachází stavový panel s dalšími ovládacími prvky (<<fig:basicAppLayout.buttonsPanel>>).
Je vždy viditelný a jeho účelem je umožnit přepínání mezi zrovna aktivní obrazovkou (viz <<sec:mainWindow>>), umožnit připojení k backendu a informovat uživatele o momentálním stavu připojení k backendu.
Více viz <<sec:buttonsPanel>>.

.Stavový panel
image::2023-07-29T15-13-41-633Z.png[Stavový panel,id="fig:basicAppLayout.buttonsPanel"] 

Sekce hlavní obrazovky (<<fig:basicAppLayout.mainScreen>>) slouží k zobrazení a ovládání aktivní obrazovky aplikace. Více viz <<sec:mainWindow>>

.Hlavní obrazovka
image::2023-07-29T15-14-06-462Z.png[Hlavní obrazovka,id="fig:basicAppLayout.mainScreen"] 

Poslední sekce se skládá z konzole pro výstup (<<fig:basicAppLayout.console>>).
Jsou do ní zapisovány informační, varovné a chybové zprávy (viz <<sec:console>>).
