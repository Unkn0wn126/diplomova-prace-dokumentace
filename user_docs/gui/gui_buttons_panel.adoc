== Stavový panel

Stavový panel (<<fig:buttonsPanel.buttonsPanel>>) se nachází ve druhé sekci okna aplikace.
Jeho účelem je uživateli umožnit změnu aktivní obrazovky (<<fig:buttonsPanel.connectButton>>), připojit se k backendu (<<fig:buttonsPanel.activeScreenComboBox>>) a informovat ho o momentálním stavu připojení (<<fig:buttonsPanel.connectionStatusInfo>>).
