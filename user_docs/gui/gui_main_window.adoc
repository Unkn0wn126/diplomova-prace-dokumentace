[#sec:mainWindow]
== Hlavní obrazovka

Hlavní obrazovka (<<fig:mainWindow.defaultMainScreen>>) se nachází ve třetí sekci okna aplikace.
Většina interakcí s funkcemi této aplikace pro daný režim probíhají právě v této části.

V současnou chvíli jsou pro tuto obrazovku podporovány následující režimy:

* Model
* Scény

Pro způsob jejich přepínání viz <<sec:switchScreens>>
