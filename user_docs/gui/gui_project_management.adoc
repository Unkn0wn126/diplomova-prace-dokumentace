[#sec:projectManagement]
== Správa projektu

Projekt se skládá z následujících částí, které lze uložit a načíst:

* Model
* Úchopové body
* Definice scén
* Scény

Vždy lze mít v aplikaci načtený pouze jeden projekt, ale zároveň je možné mít otevřeno vícero instancí této aplikace.

[#sec:createNewProject]
=== Vytvoření nového projektu

Nový projekt je automaticky vytvořen při prvním otevření aplikace.
Později jej lze však také vytvořit manuálně pomocí nabídky menu:Soubor[Nový (Ctrl + N)] v nástrojové liště (viz <<sec:menuBar>>) nebo pomocí klávesové zkratky kbd:[Ctrl+N].

Po vytvoření nového projektu se zobrazí informativní dialog o dokončené operaci (<<fig:projectManagement.newProjectCreatedDialog>>).
Nutno podotknout, že tato operace vždy vede k přepnutí aktivní obrazovky do režimu Model.

[#sec:saveProject]
=== Uložení projektu

Po provedení požadovaných operací je možné projekt uložit pomocí nabídky menu:Soubor[Uložit (Ctrl + S)] či menu:Soubor[Uložit jako... (Ctrl + Shift + S)] pokud je potřeba vybrat jiné místo pro uložení projektu.
Alternativně lze ke stejnému účelu využít klávesových zkratek kbd:[Ctrl+S] a kbd:[Ctrl+Shift+S].

První zmíněná možnost provede uložení do naposledy použitého souboru, pokud takový existuje.
V opačném případě se zachová jako druhá zmíněná možnost a umožní výběr požadovaného souboru.

Pro výběr souboru, do kterého se má projekt uložit se zobrazí dialog pro výběr souboru (<<fig:projectManagement.saveProjectDialog>>).
Tento dialog nevznikl jako součást této aplikace a bylo jej nutné použít pro získání možnosti interakce se soubory v sestaveném projektu Unity.

.Dialog pro uložení souboru
image::2023-07-29T18-26-30-644Z.png[Dialog pro uložení souboru,id="fig:projectManagement.saveProjectDialog"] 

Projektu je potřeba přiřadit jméno (<<fig:projectManagement.saveProjectDialogWithFilledName>>).
To v rámci dialogu nemusí obsahovat koncovku formátu uloženého projektu (.json) a v případě její absence bude automaticky přidána.
