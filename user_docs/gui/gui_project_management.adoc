[#sec:projectManagement]
== Správa projektu

Projekt se skládá z následujících částí, které lze uložit a načíst:

* Model
* Úchopové body
* Definice scén
* Scény

Vždy lze mít v aplikaci načtený pouze jeden projekt, ale zároveň je možné mít otevřeno vícero instancí této aplikace.

[#sec:createNewProject]
=== Vytvoření nového projektu

Nový projekt je automaticky vytvořen při prvním otevření aplikace.
Později jej lze však také vytvořit manuálně pomocí nabídky menu:Soubor[Nový (Ctrl + N)] v liště s menu (viz <<sec:menuBar>>) nebo pomocí klávesové zkratky kbd:[Ctrl + N].

Po vytvoření nového projektu se zobrazí informativní dialog o dokončené operaci (<<fig:projectManagement.newProjectCreatedDialog>>).
Nutno podotknout, že tato operace vždy vede k přepnutí aktivní obrazovky do režimu Model.

[#sec:saveProject]
=== Uložení projektu

Po provedení požadovaných operací je možné projekt uložit pomocí nabídek v liště s menu (viz <<sec:menuBar>>) menu:Soubor[Uložit (Ctrl + S)] a menu:Soubor[Uložit jako... (Ctrl + Shift + S)], pokud je potřeba vybrat jiné místo pro uložení projektu.
Alternativně lze ke stejnému účelu využít klávesových zkratek kbd:[Ctrl + S] a kbd:[Ctrl + Shift + S].

První zmíněná možnost provede uložení do naposledy použitého souboru, pokud takový existuje.
V opačném případě se zachová jako druhá zmíněná možnost a umožní výběr požadovaného souboru.

Pro výběr souboru, do kterého se má projekt uložit se zobrazí dialog pro výběr souboru (<<fig:projectManagement.saveProjectDialog>>).
Tento dialog nevznikl jako součást této aplikace a bylo jej nutné použít pro získání možnosti interakce se soubory v sestaveném projektu Unity.

.Dialog pro uložení souboru projektu
image::2023-07-29T18-26-30-644Z.png[Dialog pro uložení souboru projektu,id="fig:projectManagement.saveProjectDialog"] 

Projektu je potřeba přiřadit jméno (<<fig:projectManagement.saveProjectDialogWithFilledName>>).
To v rámci dialogu nemusí obsahovat koncovku formátu uloženého projektu (.json) a v případě její absence bude automaticky přidána.

.Dialog pro uložení souboru projektu s vyplněným jménem
image::2023-07-29T18-30-56-056Z.png[Dialog pro uložení souboru projektu s vyplněným jménem,id="fig:projectManagement.saveProjectDialogWithFilledName"] 

Po úspěšném uložení je zobrazen dialog zobrazující plnou cestu k uloženému souboru (<<fig:projectManagement.projectSavedSuccessfullyDialog>>).

.Dialog informující o úšpěšném uložení projektu
image::2023-07-29T18-31-59-385Z.png[Dialog informující o úšpěšném uložení projektu,id="fig:projectManagement.projectSavedSuccessfullyDialog"] 

Nutno upozornit, že při uložení projektu nedochází k uložení transformací kamery sloužící k náhledu na zobrazovaný model, ani k uložení aktivního režimu obrazovky či vybraných položek v seznamu.

[#sec:loadProject]
=== Načtení projektu ze souboru

Projekt lze načíst pomocí nabídky menu:Soubor[Otevřít (Ctrl + O)] v liště s menu (viz <<sec:menuBar>>) či klávesovou zkratkou kbd:[Ctrl + O].
Pro výběr souboru, ze kterého se má projekt načíst se zobrazí dialog pro výběr souboru (<<fig:projectManagement.loadProjectDialog>>).
Jak je zřejmé, i zde lze pracovat pouze se soubory s koncovkou _.json_.

.Dialog pro otevření souboru projektu
image::2023-07-29T19-48-20-230Z.png[Dialog pro otevření souboru projektu,id="fig:projectManagement.loadProjectDialog"] 

V případě, že nahrávaný soubor neobsahuje validní data projektu, zobrazí se okno s chybou a do konzole bude chyba vypsána též (<<fig:projectManagement.loadInvalidProjectFileResult>>).

.Výsledek pokusu o načtení nevalidního souboru
image::2023-07-29T19-55-34-774Z.png[Výsledek pokusu o načtení nevalidního souboru,id="fig:projectManagement.loadInvalidProjectFileResult"] 

Pokud byl projekt ze souboru úspěšně načten, zobrazí se dialogové okno a informace je též zapsána do konzole (<<fig:projectManagement.loadProjectSuccess>>).
Režim obrazovky se zároveň přepne na Model a s projektem je poté možné dále pracovat (<<fig:projectManagement.exampleProjectLoadedFromFile>>).
